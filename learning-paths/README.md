# Learning Paths

This folder contains step-by-step learning programs, not standalone concept encyclopedias. Each path should tell you what to learn first, what to practise, how to measure progress, and how to use references without skipping the thinking.

## Available learning paths

| Path | Goal | Best for |
|---|---|---|
| [DSA From Zero — Learn to Think, Recognize Patterns, and Solve Problems](dsa/README.md) | A structured route from “I don't know how to start” to understanding common data structures, algorithms, problem-solving patterns, and efficient solutions | Beginners learning DSA for coursework, placements, projects, and long-term software engineering |

## How to use a learning path

1. Read the path's start page and follow the suggested order.
2. Practise the work before reading a completed solution.
3. Record your mistakes and revisit them.
4. Use linked repositories as references to understand implementations—not as a replacement for reasoning.
5. Update your plan based on what you can explain and solve independently, not only on how many checkboxes you completed.
