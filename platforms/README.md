# Platforms and Technology Ecosystems

Use this folder for practical, standalone guides to platforms, cloud providers, developer ecosystems, and hosted services that engineers use to build, deploy, operate, and scale applications.

Examples include:
- Cloud platforms: AWS, Microsoft Azure, Google Cloud
- Deployment and hosting: Vercel, Netlify, Render, Fly.io
- Developer platforms and collaboration: GitHub and GitLab
- Application infrastructure and data services: Docker, Kubernetes, Supabase, Firebase
- AI development platforms and model-serving services

## What belongs here?

Put a document here when the main subject is a specific platform or ecosystem and you want to understand:
- What the platform is and what problems it solves
- Its major services and building blocks
- How it fits into a real application architecture
- How it compares with related tools
- Pricing, quotas, account setup, and operational considerations
- Security, permissions, and common beginner mistakes
- When it is useful and what to learn next

## How this differs from the other folders

- Use `concepts/` for general engineering concepts such as APIs, HTTP, authentication, RAG, and fine-tuning.
- Use `platforms/` for a platform-specific guide, such as AWS services and how they fit together.
- Use `cheat-sheets/` for concise command and syntax references.
- Use `builds/` for runnable projects and experiments.
- Use `notes/` for learning-session notes.
