# Platforms and Technology Ecosystems

This folder contains guides to specific platforms and ecosystems used to build, deploy, operate, and scale software.

**Each platform has its own folder, and its complete guide lives in that folder's `README.md`.**

## Platform Guides

| Folder | What it covers |
|---|---|
| [AWS — Amazon Web Services](aws/README.md) | Cloud computing, EC2, S3, RDS, Lambda, IAM, application architecture, pricing, security, and a learning path |
| [Google Cloud Platform (GCP)](google-cloud/README.md) | Projects, Compute Engine, Cloud Run, Cloud Storage, databases, BigQuery, Vertex AI, IAM, billing, and a beginner learning path |
| [Firebase](firebase/README.md) | Authentication, Firestore, file storage, hosting, Cloud Functions, basic web examples, security rules, and pricing |

## What Belongs Here?

Examples of future platform guides include:
- Cloud providers: AWS, Google Cloud, and Microsoft Azure
- Deployment platforms: Cloud Run, Vercel, Netlify, Render, and Fly.io
- Containers and orchestration: Docker and Kubernetes
- App-development platforms: Firebase and Supabase
- Developer ecosystems and hosting services

## How This Differs from Other Folders

- Use `concepts/` for general ideas such as APIs, authentication, HTTP, RAG, and fine-tuning.
- Use `platforms/` for a specific platform's services, architecture, setup, pricing, and trade-offs.
- Use `cheat-sheets/` for concise command and syntax reminders.
- Use `builds/` for runnable applications and experiments.

Add new platform-specific guides as their own folders, each with a `README.md`.
