# Learning Notes

Use this folder for dated or topic-based notes from classes, tutorials, documentation, videos, and study sessions.

## Suggested format

- **Date / session:**
- **Topic:**
- **What I learned:**
- **Important examples:**
- **What is still unclear:**
- **Next steps:**

Keep these notes useful for future revision. Move a topic into `concepts/` when it deserves a complete, standalone explanation.
