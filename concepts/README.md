# Engineering Concepts

Use this folder for clear, standalone explanations of engineering ideas and how they work.

A good concept document should include:
- A plain-English definition
- Why the concept exists and what problem it solves
- A real-world analogy, where useful
- A technical explanation and a simple example
- Related concepts and common misconceptions
- A short summary and questions for revision
