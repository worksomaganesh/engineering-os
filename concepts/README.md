# Engineering Concepts

This folder contains standalone explanations of engineering concepts. **Each concept has its own folder and its full guide is stored in that folder's `README.md`.**

Use a concept guide when you want to understand what something is, why it exists, how it works, when it is useful, what its limitations are, and how it relates to other engineering ideas.

## Where Related Knowledge Goes

- Use `platforms/` for guides about a specific cloud provider or technology ecosystem.
- Use `cheat-sheets/` for compact command references and quick revision.
- Use `notes/` for session-specific learning notes.
- Use `builds/` for runnable experiments and projects.
- Use `questions/` for standalone question-and-answer records.

## Documentation Standard

Each concept guide should aim to explain:
1. The definition and problem it solves.
2. A beginner-friendly analogy, when useful.
3. How it works technically, step by step.
4. Practical examples and where it is used.
5. Similarities, differences, limitations, and security considerations.
6. Common misconceptions and revision questions.
